二、安装
----------------------------------------------------------------
1. 卸载手机上的原版《嫣汐》（签名不同，无法直接覆盖升级）。
2. 允许“安装未知来源应用”，安装 yanxi_offline_v1.0.6_plus3.apk。
   若已装过 plus / plus2 版，可直接覆盖安装（同一签名），旧存档会保留，
   其中异常的好感度档位/进度值会在进入主界面时自动纠正。
3. 首次启动会依次经过开屏动画、欢迎视频，直接进入主界面（不再联网校验版本）。

如需保留旧版数据，请自行用备份工具处理；本包不保证继承旧存档。

三、可用功能
----------------------------------------------------------------
- Live2D 立绘显示、待机动作、表情切换（完全本地）
- 点击 / 拖拽 / 长按 头部、脸、身体、手、腿、裙子等部位触发对应动作

- 本地告白 / 分手（原 user/saylove、user/saygoodbye 接口已离线化）
- 点击头像进入离线「个人信息」页（替换原云端 MyHomeActivity）

四、对话功能（API 优先 + 本地台词兜底）
----------------------------------------------------------------
1. 入口：点击主界面聊天图标或点击气泡，从屏幕底部弹出对话窗。
   左上角标题、背景、输入框、发送按钮均复用原版素材，界面接近原版。
2. 默认使用本地台词：从原作的 240 余条互动台词中按关键词随机回复。
3. 想要自由对话：点对话窗右上角「设置」填写 OpenAI 兼容接口。
   - Base URL：https://api.deepseek.com（DeepSeek）
                 https://api.openai.com/v1（OpenAI）
                 https://api.moonshot.cn/v1（Moonshot）
   - API Key：你自己的密钥（仅保存在本机 SharedPreferences，不会
     发送到除该服务商之外的任何地方）
   - 模型：deepseek-chat / gpt-4o-mini / moonshot-v1-8k 等
   - 可点「测试连接」验证；点「清除 Key」回到本地台词模式。
4. 若 API 请求失败（网络、额度和鉴权问题），会自动回落到本地台词，
   并在屏幕下方提示失败原因。
5. 表情驱动：每次回复会随机切换一个立绘表情，同时通过事件总线
   live2d_show_mini_dialog 弹出原版迷你气泡，观感接近原版聊天。

安全提示：请勿在公共设备上保存自己的 API Key。

五、剧本导入（热更，不用重新打包）
----------------------------------------------------------------
原版剧本在 assets 中，运行时从 files 目录优先读取覆盖文件。本包已
接入该机制，可自行续写台词、动作而无需重新编译 APK。

1. 导入：对话窗「设置」→「导入剧本 JSON」，用系统文件选择器选中你的
   JSON 文件，程序会先校验 JSON 合法性，再写入
     /data/data/com.muta.yanxi/files/yanxi1.json
   导入成功后提示“剧本已导入，重启嫣汐后生效”。
2. 生效：完全退出并重新启动游戏后生效。
3. 恢复：设置 →「恢复内置剧本」，删除上述覆盖文件，回到原版剧本。
4. 格式：与原版剧本一致（JSON 对象，包含动作、台词、value.min/max
   等字段），建议先备份原版剧本再改；格式写错会导致该档位剧本不加载。

六、好感度机制（本地结算）
----------------------------------------------------------------
原版好感度由服务器下发（intimatestatus / intimatecount / deltavalue
/ uplimit / downlimit）。单机版改为本地结算，规则如下：

1. 每次互动按剧本 value.min ~ value.max 随机产生一个增减值，
   先累加到缓存（sync_cache_value），互动次数 +1（sync_tap_count）。
2. 每累计 9 次互动结算一次：
   - 累计值为正 → 好感等级 +1（上限 10）
   - 累计值为负 → 好感等级 -1（下限 1）
   - 累计值为 0 → 等级不变
3. 等级提升时累计分 +1000，下降时 -500（不低于 0）；未跨档则分数不变。
   跨档时档位内进度归零；未跨档时进度保持原值，缓存清空重新累计。
4. 结算后进度条与立绘状态档位立即刷新；跨档时会弹出提示
   “好感度提升了！”或“好感度下降了……”。
5. 所有数据仍存在原版 SharedPreferences("live2d") 中，卸载即清空。

修复说明（plus2）：
- 原版剧本只有 1~6、8~10 档，缺第 7 档。本地结算若升到 7 档，
  剧本会回落到 default，而 default 里没有 tap 系列节点，
  表现为“点哪里都没反应”。现在升/降档会自动跳过 7。
- 档位一律限制在 1~10，进度值与累计分不允许为负。
  之前异常存下的 0 档、-500 进度会在进入主界面/下次互动时被纠正。

注：原来的服务端“跨档阈值”“每日上下限”等字段不再参与计算，
等级仅由本地 9 次结算决定。

七、告白 / 分手（本地版）
----------------------------------------------------------------
原版表白是把好感度、互动次数和你写的文本 POST 到 user/saylove，
由服务器判断成败；分手走 user/saygoodbye。服务停运后这两个接口已不可用，
本包改为完全本地执行，入口位置与原版一致（好感度达到条件后的告白入口、
以及个人信息页/原版菜单中的“分手”）。

1. 表白成败怎么判：
   - 已在对话窗「设置」里填好 API Key → 由你自己配置的大模型判分。
     程序会把嫣汐的人设和你的表白文本发给模型，要求它只回一行 JSON：
     {"accept":true,"reply":"一句符合人设的回应"}
     模型说 accept=true 即表白成功，reply 会一并显示在结果弹窗里。
   - 没有配置 API Key（或请求失败）→ 使用本地规则兜底，并在弹窗末尾
     注明“本次使用本地判定”。本地规则：太短（少于 8 个字）或几乎重复
     同一句话直接失败；否则好感档位 ≥5 时通过，低档位有 25% 概率通过。
2. 结算规则（本地）：
   - 表白成功：好感进度 +400，每凑满 1000 升一档（跳过第 7 档，上限 10）
   - 表白失败：好感不变，仅给出嫣汐的回应
   - 分手：好感清零（进度归 0）并降一档（下限 1，跳过第 7 档）
3. 结果会以弹窗展示：标题「表白成功 / 表白失败 / 分手」，
   内容含嫣汐的回应与「好感度 ±N，当前第 s 档（进度 x/1000）」。
4. 表白文本、模型回复都只在本机使用，不上传任何第三方服务器
   （除你自己配置的那家大模型接口）。

提示：AI 判分需要网络与可用额度；离线环境下会自动走本地规则。

----------------------------------------------------------------
八、个人信息页（离线）
----------------------------------------------------------------
原版点头像是进入 MyHomeActivity，页面数据来自服务器，停服后打不开。
本包改为进入本地「个人信息」页：

- 昵称：默认“玩家”，点「修改」可改，存在本机（profile_nickname）
- 与嫣汐相伴天数：按首次启动时间计算
- 好感度卡片：当前档位（1~10）、档位进度条、进度值 /1000
- 本地记录：互动次数、已解锁回忆条数
- 嫣羽 / 人气、作品 / 歌曲：原数据在云端，离线不可用，页面中已注明
- 页面底部说明：只读取本地存档，表白与聊天内容不会上传

如需清空个人信息页里的昵称等数据，卸载重装即可（与存档一同清空）。

九、已停用 / 已降级的功能
----------------------------------------------------------------
- 账号登录（原仅支持 QQ / 微信 + 环信登录）：已移除入口，点击相关菜单会

十、已知限制与风险
----------------------------------------------------------------
1. 本次改造只做了静态构建与签名校验（apktool 回编译成功、
   apksigner v1/v2/v3 校验通过、包名与版本号未变），
   缺少真机 / 模拟器，未做运行时验证，请自行安装实测。
2. 重点需要实测的四处：
   - 底部对话窗弹出后键盘是否遮挡输入框（已设 adjustResize）
   - AI 回复切换表情的观感（表情索引随机取 0~13）
   - 导入剧本后 files/yanxi1.json 是否被正确加载
   - plus3 新增：点击头像能否打开个人信息页、表白/分手弹窗与好感度刷新
     （这两个功能通过反射调用原库存档方法，若个别机型出现异常，
     请反馈弹窗内容与操作路径）
3. 若个别菜单点击仍出现异常或闪退，多为原版第三方 SDK（个推、百度定位、
   环信等）在无网络环境下初始化所致，可反馈具体操作路径再定位。
4. 部分原版联网文案可能残留，属于正常现象，不影响本地 Live2D 与对话。
5. 修改后包体约 39.1 MB，与第一版基本一致。
